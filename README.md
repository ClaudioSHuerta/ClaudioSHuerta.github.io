## About this project
This is my personal GitHub Pages site, where I keep notes, cheat sheets, and things I learn while building apps for the Apple ecosystem — Swift, SwiftUI, SwiftData, WidgetKit, and more.
## 📓 Notes
-   [Swift & iOS Cheat Sheet](swift-notes.md) — a growing collection of notes covering Swift fundamentals, UIKit vs. SwiftUI lifecycles, the Observation framework, Swift Concurrency, dependency injection, and testability.
